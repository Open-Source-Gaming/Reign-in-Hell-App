# References Directory

This directory contains proprietary reference materials used during development that are not redistributed with the project.

## Required Materials

Anyone working on this project must purchase their own copy of the following materials and place them in this directory:

### Reign in Hell Rulebook

- **Filename**: `reign_in_hell_v3.pdf` (or latest version)
- **Publisher**: Snarling Badger Studios
- **Authors**: Adam Loper and Vince Venturella
- **Purchase**: Available from Snarling Badger Studios' store
- **Purpose**: Required for understanding game mechanics, demon types, philosophies, combat systems, and campaign scenarios

## Why This Directory Exists

The companion app needs to understand the game's domain model (cabals, demons, philosophies, combat mechanics, soul dice, etc.) to provide accurate digital tools. However, we do not redistribute any copyrighted content from the rulebook.

This directory is gitignored (except for this README) to ensure no proprietary content is accidentally committed to version control.
