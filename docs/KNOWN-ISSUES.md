## When to Fill This In

- When a bug is known but not yet fixed.
- When a limitation is accepted for the current phase.
- When a workaround exists for a known problem.

## Severity Levels

- **Critical**: System is unusable or data loss occurs.
- **High**: Major feature is broken with no workaround.
- **Medium**: Feature is broken but a workaround exists.
- **Low**: Minor inconvenience or cosmetic issue.
