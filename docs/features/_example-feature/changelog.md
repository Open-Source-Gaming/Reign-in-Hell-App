## Format

Use [Keep a Changelog](https://keepachangelog.com/) format within each feature.

Categories:

- **Added**: New functionality.
- **Changed**: Modifications to existing functionality.
- **Fixed**: Bug fixes.
- **Removed**: Removed functionality.

Each entry should be a single line describing the change. Link to the relevant PR or commit when available.
