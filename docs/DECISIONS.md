## Overview

This project uses Architecture Decision Records (ADRs) to document significant technical decisions. ADRs are immutable once accepted. If a decision is reversed, a new ADR supersedes the old one.

See [docs/adr/README.md](adr/README.md) for the ADR process and template.

## Status Definitions

- **Proposed**: Under discussion. Not yet accepted.
- **Accepted**: Approved and in effect.
- **Deprecated**: No longer relevant but was once accepted.
- **Superseded**: Replaced by a newer ADR. Links to the replacement.
- **Template**: Reference template, not a real decision.
